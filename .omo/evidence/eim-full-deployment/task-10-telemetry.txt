Module Details:

telemetry.py:
  - class TelemetryListener(project, region, polling_interval=60, ledger_writer=None)
  - start() → background daemon thread, _poll_gcp() every polling_interval seconds
  - _poll_gcp() → subprocess.run('gcloud run services list --format=json'), checks conditions
  - _poll_cloudflare() → stub placeholder (CF_REMEDIATION_QUEUE env var)
  - stop() → signals thread, joins
  - _write_anomaly() → writes to LedgerWriter as type: "telemetry_anomaly"
  - Graceful: handles FileNotFoundError (no gcloud), TimeoutExpired, JSONDecodeError, subprocess errors

knowledge_steward.py:
  - class GeminiKnowledgeSteward()
  - analyze(anomaly_report, rag_context=None) → {diagnosis, recommended_action, confidence}
  - Uses google.generativeai with gemini-2.0-flash model
  - API key from GEMINI_API_KEY env var
  - Prompt: system prompt + anomaly data + RAG context + JSON output instruction
  - Stub: GEMINI_API_KEY missing → {"diagnosis": "Knowledge Steward unavailable", ...}
  - Graceful: API key missing, import error, API call failure all → stub response

rag_connector.py:
  - class OpenVikingRAG(corpus_path=None)
  - query(anomaly_description, top_k=3) → list[dict] with title, path, content, score
  - Reads *.md from rag/docs/openviking/ directory
  - Tokenizes query, filters stop words, scores by keyword frequency
  - Falls back to [] if corpus directory doesn't exist
  - Auto-resolves path: env var → well-known relative paths → cwd
