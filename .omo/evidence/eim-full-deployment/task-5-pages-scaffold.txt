## Design Decisions
- Palette: Deep slate backgrounds (#080b12–#141924) with cool cyan accent (#38bdf8) — distinct EIM identity
- Tokens: Follows existing `cloudflare/src/style.css` pattern (same structure, different palette)
- No hardcoded hex colors in HTML or app code; all colors reference CSS custom properties
- `#fff` only used in CSS mask gradients (browser rendering requirement)
- No emojis — all icons are inline SVGs
- No frameworks — vanilla HTML/CSS/JS
- Responsive: mobile hamburger menu with slide-in sidebar + overlay; tabs stack vertically at 480px
- GPU-composited animations only: transform, opacity transitions, no layout-property animation
- Password NEVER stored or echoed — client sends raw password to server, server hashes and compares, returns boolean only

## Deployment Notes
- ACCESS_PASSWORD_HASH must be set via: wrangler secret put ACCESS_PASSWORD_HASH
- Generate hash: echo -n "your-password" | sha256sum
- Deploy gate: [HUMAN-APPROVAL-REQUIRED] before `wrangler pages deploy`
- Local dev: `cd cloudflare/pages/eim && npx wrangler pages dev . --port 8790`
