## Task 6 — MediaPipe FaceLandmarker WASM Integration
### Evidence of completion — 2026-07-28

#### Files created
- `cloudflare/pages/eim/mediapipe-face-tracker.js` (new) — standalone ES module
  - 280+ lines, vanilla JS, zero framework deps
  - Loads `@mediapipe/tasks-vision@0.10.18` from jsDelivr CDN (`+esm`)
  - Loads `face_landmarker.task` (float16/latest) from Google Cloud Storage
  - Class `FaceTracker extends EventTarget` — default export
  - `FilesetResolver.forVisionTasks(WASM_CDN)` for WASM init
  - `FaceLandmarker.createFromOptions()` config: runningMode VIDEO, outputFaceBlendshapes true, outputFacialTransformationMatrixes false, numFaces 1, delegate GPU
  - `start()`: requests webcam via getUserMedia, creates hidden video element, starts rAF detection loop
  - `stop()`: stops tracks, cleans up video, cancels rAF, clears canvas
  - Detection loop: rAF with `video.currentTime !== lastVideoTime` frame dedup
  - `detectForVideo(videoElement, performance.now())` for inference
  - Extracts 52 blendshape scores into key-value object
  - Extracts 478 face landmarks (x, y, z normalized coords)
  - Draws landmarks as semi-transparent cyan dots on overlay canvas (iris landmarks in indigo)
  - Canvas resizes on window resize via ResizeObserver
  - Dispatches CustomEvent: `blendshape` (52 scores), `landmarks` (478 points), `status` (state machine)
  - Error handling: camera denial → 'no-camera' status; WASM/model failure → 'error' status
  - `detectOnce()` returns last FaceLandmarkerResult synchronously
  - `getBlendshapes()` returns last blendshape object synchronously
  - Adds `addEventListener()` via EventTarget inheritance

#### Known limitations
- Face mesh drawn as landmark points (thin cyan dots with indigo iris highlights) — full wireframe triangulation would require importing FACEMESH_TESSELATION from @mediapipe/face_mesh (legacy API), not available in tasks-vision
- Model version pinned to `float16/latest` — if Google updates the model, behavior may change
- WebGL GPU delegate requires browser WebGL support; falls back to CPU if unavailable
