Files Created:
  ✅ cloudflare/pages/eim/functions/api/tavus/conversation.js
     Pages Function proxying Tavus REST API POST /api/tavus/conversation.
     Reads TAVUS_API_KEY from env (never exposed to client).
     Supports optional persona_id/replica_id overrides from request body.
     Error handling: 405 for non-POST, 500 for missing API key, 502 for Tavus unreachable.
     Returns { conversation_url, conversation_id, status, created_at }.

  ✅ cloudflare/pages/eim/tavus-avatar.js
     ES module exporting TavusAvatar extends EventTarget.
     Uses Daily.co IFrame API from CDN (@daily-co/daily-js).
     connect(conversationUrl) creates Daily IFrame and joins room.
     disconnect() leaves meeting, removes iframe, cleans up listeners.
     getStatus() returns current connection state.
     Dispatches status events: connecting, connected, disconnected, error.

  ✅ cloudflare/pages/eim/mediapipe-tavus-bridge.js
     ES module exporting MediapipeTavusBridge extends EventTarget.
     attach(faceTracker) bridges FaceTracker blendshape events.
     Throttles output to 500ms with significant change detection (≥0.05 delta).
     Infers emotion (happy/sad/angry/surprised/worried/neutral) from blendshapes.
     Dispatches tavus-context events with emotion, top expressions, and raw data.
     detach() cleans up event listeners.

Edge Cases Handled:
  - Missing/invalid API key → 500 error in function, logged server-side.
  - Tavus API unreachable → 502 error with detail.
  - Non-JSON response from Tavus → 502 error.
  - Already-connected avatar → warns and disconnects before reconnecting.
  - Missing container element → logged error.
  - Bridge attach with no face tracker → bridge created but not attached.
  - Multiple initAvatar() calls → guarded by avatarConnected/avatarConnecting flags.
